# Reverse SSH Tunnel

Experimental outbound SSH tunnel to your own server, with optional autossh.
No host networking, Docker socket or privileged operation required.

[English setup](DOCS.md) · [Deutsche Einrichtung](DOCS.de.md)

Includes beginner setup recipes for direct VPN access, VPN-to-loopback NAT and
a reverse proxy. One HA/OpenVPN/NAT deployment was manually verified; keep
existing remote access until your own parallel test has succeeded.
